Importing from qiime2

strollur includes the function strollur::read_qiime2() as well as several functions to read qiime2 output files individually. To create a dataset from the outputs of the qiime2, run the following:

qza_files <- c(
  strollur_example("rep_seqs.qza"),
  strollur_example("table.qza"),
  strollur_example("taxonomy.qza"),
  strollur_example("rooted-tree.qza")
)

data <- strollur::read_qiime2(
  qza = qza_files,
  metadata = strollur_example("sample_metadata.tsv"),
  dataset_name = "qiime_moving_pictures"
)

Reading Individual Files

  • strollur::unpack_qiime2_artifact() unpacks qiime2 qza files and returns an artifact
  • strollur::read_qiime2_feature_table() reads a qiime2 qza file containing bin data
  • strollur::read_qiime2_taxonomy() reads a qiime2 qza file containing containing taxonomy data
  • strollur::read_qiime2_metadata() read qiime2 tsv table containing metadata

To create a dataset and read the individual files, you can use the functions below. First let’s create a dataset named my_data.

my_data <- strollur::new_dataset(dataset_name = "my_data")

To decompress the individual qza files, you can use the strollur::unpack_qiime2_artifact(). unpack_qiime2_artifact will extract a folder containing the data, versioning and provenance information. Let’s take a look at the rep_seqs.qza file first.

fasta_artifact <-
  strollur::unpack_qiime2_artifact(qza = strollur_example("rep_seqs.qza"))

fasta_artifact is a list. To add the FASTA data to your dataset you can use the strollur::read_fasta() function:

fasta_file <- file.path(
  getwd(), "rep_seqs", fasta_artifact$uuid, "data",
  "dna-sequences.fasta"
)
fasta_data <- strollur::read_fasta(fasta = fasta_file)

fasta_data is a data.frame containing sequence names, sequence nucleotide strings, and comments if provided. You can add the FASTA sequences to your strollur object using the strollur::add() function:

strollur::add(
  my_data,
  table = fasta_data,
  type = "sequence"
)
## Added 759 sequences.

You can remove the fasta_artifact using the unlink function:

unlink(file.path(getwd(), "rep_seqs"), recursive = TRUE)

Now that we have added the FASTA sequences, let’s read the abundance data found in the table.qza file. Since we know that the sequences are in fact features, we will assign the abundances to the sequences and then we can assign the sequences to bins to create Amplicon Sequence Variant asv clusters. Let’s use the strollur::read_qiime2_feature_table() function to extract the abundance table.

abundance <- strollur::read_qiime2_feature_table(strollur_example("table.qza"))

strollur::assign(
  my_data,
  table = abundance$data,
  type = "sequence_abundance",
  table_names = list(sequence_name = "bin_name")
)
## Assigned 759 sequence abundances.
strollur::assign(
  my_data,
  table = abundance$data,
  type = "bin",
  bin_type = "asv",
  table_names = list(sequence_name = "bin_name")
)

Now that we have added the abundance data and assigned the sequences to bins, let’s take a look at the taxonomic classifications provided in the taxonomy.qza file. We will use the strollur::read_qiime2_taxonomy() function to extract the feature classification table.

taxonomy <- strollur::read_qiime2_taxonomy(strollur_example("taxonomy.qza"))

strollur::assign(
  my_data,
  table = taxonomy$data,
  type = "sequence_taxonomy",
  table_names = list(sequence_name = "bin_name")
)
## Assigned 759 sequence taxonomies.

Now, lets add a tree that shows the relationships between the sequences (features).

tree_artifact <- strollur::unpack_qiime2_artifact(
  qza =
    strollur_example("rooted-tree.qza")
)

We can read the tree using the ape::read.tree() function.

tree_file <- file.path(
  getwd(), "rooted-tree", tree_artifact$uuid, "data",
  "tree.nwk"
)
sequence_tree <- ape::read.tree(tree_file)

You can add the tree to your dataset as follows:

strollur::add(data, table = sequence_tree, type = "sequence_tree")

You can remove the tree_artifact using the following:

unlink(file.path(getwd(), "rooted-tree"), recursive = TRUE)

Lastly, let’s read the metadata provided by qiime2 using the strollur::read_qiime2_metadata() function.

metadata <- strollur::read_qiime2_metadata(
  metadata =
    strollur_example("sample_metadata.tsv")
)

To add the metadata to the my_data dataset, run the following:

strollur::add(my_data,
  table = metadata,
  type = "report",
  report_type = "metadata"
)
