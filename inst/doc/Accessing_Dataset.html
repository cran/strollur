Accessing Data

Overview

The strollur package stores data associated with your Amplicon Sequence Analysis. This tutorial will familiarize you with some of the functions available in the strollur package. If you haven’t reviewed the “Getting Started” tuturial, we recommend you start there.

Loading the example dataset

We can use the strollur::miseq_sop_example() function to create a dataset object from the Miseq SOP Example.

miseq <- strollur::miseq_sop_example()

Accessing Your Data

The strollur package includes several functions to access your sequence data.

strollur::names() - The names function is an extension of base R’s names function. It allows you to get the name of your dataset or the names of the sequences, bins, samples, treatments and reports in your dataset.

strollur::count() - The count function allows you to get the number of sequences, bins, samples and treatments in your dataset.

strollur::abundance() - The abundance function can be used to access the abundance data for sequences, bins, samples, and treatments.

strollur::report() - The report function can be used to access the various data associated with your dataset.

strollur::summary() - The summary function allows you to summarize sequences, your custom reports, and scrapped data.

strollur::names

The strollur::names() function allows you to get the names of sequences, bins, samples, treatments and reports. Let’s take a closer look at how use it.

To get the name of the dataset, set the type parameter to dataset:

strollur::names(miseq, type = "dataset")
#> [1] "miseq_sop"

To get the names of the sequences in your dataset, set the type parameter to sequence:

all_sequences <- strollur::names(
  miseq,
  type = "sequence",
  distinct = FALSE
)
length(all_sequences)
#> [1] 2425
head(all_sequences, n = 5)

strollur::count

The strollur::count() function allows you to get the number of sequences, bins, samples and treatments in your dataset.

To find the total number of sequences in the dataset, run the following:

strollur::count(
  miseq,
  type = "sequence",
  distinct = FALSE
)
#> [1] 113963

To find the number of unique sequences in the dataset, set distinct = TRUE:

strollur::count(
  miseq,
  type = "sequence",
  distinct = TRUE
)
#> [1] 2425

To get total number of sequences present in sample ‘F3D0’, you can set the samples parameter. Note, these sequences will be present in the sample but may be be present in other samples as well.

strollur::count(
  miseq,
  type = "sequence",
  samples = c("F3D0"),
  distinct = FALSE
)
#> [1] 6191

To get number of unique sequences exclusive to sample ‘F3D0’:

strollur::count(
  miseq,
  type = "sequence",
  samples = c("F3D0"),
  distinct = TRUE
)
#> [1] 101

To get the number of the bins in your dataset, you need to specify the bin_type. The miseq example contains 3 bin types: otu, asv and phylotype. Let’s find the number of bins for the ‘otu’ bin type.

strollur::count(
  miseq,
  type = "bin",
  bin_type = "otu"
)
#> [1] 531

To get number of otu bins with sequences present in sample ‘F3D0’: Note these bins will have sequences from sample ‘F3D0’ and may contain sequences from other samples as well.

strollur::count(
  miseq,
  type = "bin",
  bin_type = "otu",
  samples = c("F3D0"),
  distinct = FALSE
)
#> [1] 191

To get number of otu bins exclusive to sample ‘F3D0’: Note these bins will have sequences from sample ‘F3D0’ and NO other samples will be present in the bins.

strollur::count(
  miseq,
  type = "bin",
  bin_type = "otu",
  samples = c("F3D0"),
  distinct = TRUE
)
#> [1] 14

To get the number of samples in the dataset, set type = sample:

strollur::count(miseq, type = "sample")
#> [1] 19

To get the number of treatments in the dataset, set type = treatment:

strollur::count(miseq, type = "treatment")
#> [1] 2

strollur::abundance

Now that we are familiar with the strollur::names() and strollur::count() functions. Let’s learn how we can use the strollur::abundance() function. The abundance function can be used to access the abundance data for sequences, bins, samples, and treatments. It returns a data.frame containing the requested abundance data.

To the total abundance for each sequence, set the type = sequence. This will return a 2 column data.frame containing sequence_names and abundances.

  type = "sequence",
  by_sample = FALSE

strollur allows you to include trees relating the sequences and samples within your dataset. You can access and plot them using the following functions.

sequence_tree <- strollur::report(
  miseq,
  type = "sequence_tree"
)

To access the tree that relates the samples in your dataset, set type = sample_tree.

sample_tree <- strollur::report(
  miseq,

)
